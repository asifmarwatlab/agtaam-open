# Changelog

## 1.0.0
- First release: New / Open / Save / Save As with unsaved-changes tracking.
- Tool results stored in a `<project>_data` folder; layers found again after a folder move.
- Atomic writes, corrupt-file protection, older `.json` projects still readable.
- Optional PyQt6 mixin (Save-changes prompt, window title `*`, Ctrl+N/O/S/Shift+S).
